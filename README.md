# Oya Hanım — Dijital Yıldızlar

Dijital Yıldızlar ekibinin Oya Türkmen için hazırladığı sinematik doğum günü
deneyimi. Site, bağımlılık veya build adımı gerektirmeyen statik HTML/CSS/JS ile
GitHub Pages üzerinde çalışır.

## İçeriği güncelleme

Kişi adı, metinler, yıldız mesajları, yolculuk ve galeri kayıtları `content.js`
dosyasında yönetilir.

Müziği değiştirmek için yeni MP3 dosyasını `media/soundtrack.mp3` adıyla mevcut
dosyanın üzerine yazın. Kod değişikliği gerekmez. Yeni parçayı yayınlamadan önce
lisansını doğrulayın ve `SOURCES.md` kaydını güncelleyin.

## Yerel önizleme

```powershell
python -m http.server 4173
```

Ardından `http://127.0.0.1:4173` adresini açın.
